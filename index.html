Project Overview

Problem Statement

UPI enables instant payments, which also makes it a target for fraud. Rule-based systems struggle with new fraud patterns and produce many false alarms, so smarter adaptive detection is needed.

Objectives
  • Study common UPI fraud types
  • Build ML models to classify fraudulent transactions
  • Reduce false positives
  • Analyse fraud patterns and trends
Proposed Solution

An AI-powered pipeline that analyses transaction behaviour (amount, time, frequency, device and location signals) to assign a fraud risk score and flag suspicious activity.

Common UPI Fraud Types Studied

Phishing
Fake links and messages that steal credentials or UPI PIN.
Fake Collect Requests
Victims tricked into approving a payment request.
QR Code Scams
Scanning a QR code to "receive" money that debits the account.
Account Takeover
Unauthorised access through SIM swap or stolen credentials.

Methodology

1. Data Collection

Collect or simulate UPI transaction data containing legitimate and fraudulent records.

2. Pre-processing

Clean data, handle missing values, encode categorical fields and normalise features.

3. Handling Class Imbalance

Fraud is rare, so techniques such as SMOTE or under-sampling are applied for balanced training.

4. Feature Engineering

Create behavioural features such as transaction velocity, amount deviation and time-of-day patterns.

5. Model Training

Train and compare models like Logistic Regression, Random Forest, XGBoost and neural networks.

6. Evaluation

Measure Precision, Recall, F1-score, ROC-AUC and confusion matrix, since accuracy alone is misleading for imbalanced data.

7. Analysis & Deployment

Visualise fraud trends and expose the model for real-time risk scoring.
